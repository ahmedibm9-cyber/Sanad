# SANAD — Settings Specification

Settings must be comprehensive but grouped.

## System Settings
- product language default
- deployment identity
- license status view
- global security settings
- backup defaults

## Company > Identity
- company name Arabic
- company name English
- legal names
- short name
- internal company code
- logo
- stamp
- signature

## Company > Legal & Registration
- CR number
- VAT/tax number
- tax registration data
- registration/license references
- country
- city
- address
- postal code

## Company > Contact
- phones
- email
- website

## Company > Banking
- bank name
- account name
- account number
- IBAN
- SWIFT/BIC
- bank address
- bank currency
- allow multiple bank accounts as an implementation default

## Company > Documents
- default language
- default template
- available templates
- default VAT
- VAT rate list
- currencies
- default currency
- weight units
- default weight unit
- packing units
- default Incoterm
- payment terms
- delivery terms
- Prepared By default
- show signature default by document type
- show stamp default by document type

## Company > Notifications
Category toggles.

## Company > Users & Permissions
Memberships and permission checklist.

## Company > Backup
- automatic on/off
- schedule
- retention
- last backup
- manual backup
- restore

## Company > Data
- export settings
- reference lists
- optional custom packing units/currencies

## UX rules

- use tabs
- search Settings if settings grow
- show sensible defaults
- mark critical controls
- no raw JSON editing in normal UI
