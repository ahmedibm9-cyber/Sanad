# SANAD — Notifications & Reports Specification

## Notifications

In-app notification center from V1.

Types:
- Task assigned
- Task due soon
- Task overdue
- Project status changed
- Project archived
- Project reopened
- Report Issue created
- Report Issue changed
- mention in Note
- document created
- significant document edit
- document Trash/restore
- attachment upload/remove
- permission changed
- Factory Code updated
- backup success
- backup failure
- personal To-do reminder

## Preferences

Each category can be enabled/disabled.

Critical security/system messages may be non-disableable if later designated.

## Reports

V1:
- Projects by Status
- Projects by Date
- Projects by Company
- Projects by Customer
- Documents Register
- Tasks
- Overdue Tasks
- User Activity
- Customer Export History
- Material Export History
- Audit Report

## Report filters

Use relevant:
- company
- date range
- status
- customer
- material
- user
- document type

## Export

Every V1 report:
- PDF
- Excel

## PDF
Readable management report, not raw screenshot.

## Excel
Structured data with headers, correct types and filters.
